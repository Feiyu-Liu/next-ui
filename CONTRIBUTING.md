# Contributing

Changes intentionally submitted for inclusion are licensed under MIT,
unless explicitly stated otherwise and agreed before inclusion. Keep third-party
copyright and license notices intact. Confirm that you have the right to submit
your contribution; do not copy incompatible code or private media into this repo.
No SkillDeck commercial-relicensing CLA is required for this independent package.

Use Flutter 3.47.5 / Dart 3.13.4, preserve widget behavior and public API, add tests
for observable behavior, and run the checks in README before proposing changes.
Use small Conventional Commits. Do not add credentials, personal assets, or
local configuration. CI runs unprivileged pull requests on hosted runners.
